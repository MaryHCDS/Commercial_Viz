# PROJECT_PLAN

## Visualization Design System

The library uses a consulting-style visual identity suited to executive
presentations and consulting reports. It is *inspired by* consulting
presentation design but does **not** copy any company logo, trademark, or
proprietary template.

### Core style

- White or deep navy background.
- Deep navy as the dominant color.
- Bright teal used selectively for emphasis.
- White text on dark backgrounds.
- Dark navy text on light backgrounds.
- Avoid gray as a primary visual color.
- Avoid rainbow palettes.
- Use high contrast and strong visual hierarchy.
- Use generous whitespace.
- Use bold, insight-led titles.
- Remove unnecessary borders and chart clutter.
- Prefer direct data labels over legends when possible.
- Highlight only the most important category or result in teal.
- Keep all other elements restrained.
- Charts should feel suitable for executive presentations and consulting
  reports.

### Suggested palette

| Role            | Color                | Hex       |
| --------------- | -------------------- | --------- |
| Deep navy       | dominant / background| `#001F33` |
| Teal            | selective emphasis   | `#0099B8` |
| White           | text on dark / bg    | `#FFFFFF` |
| Soft off-white  | light background     | `#F7F7F3` |
| Dark text       | text on light        | `#0B2239` |

> **Note:** This design system will later be copied into `CLAUDE.md` so it
> governs all chart implementations.
